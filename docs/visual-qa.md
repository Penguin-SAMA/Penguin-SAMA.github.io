# 视觉还原验收记录

验收日期：2026-08-30

对照对象为已确认的深色电影感整页稿及首屏、项目、技术/关于、联系四张分区稿。实际页面使用 1440×900、390×844 与 320px 宽度的 Chromium 截图逐段检查；测试截图输出到本地忽略目录 `artifacts/screenshots/`，不进入公开仓库。

## 视觉一致性清单

| 对比点 | 参考稿特征 | 首版实现 | 结论 |
| --- | --- | --- | --- |
| 色彩与氛围 | 石墨黑底、暖白字、电蓝高光、少量橙色火花 | 使用统一令牌控制画布、文字、电蓝线与橙色状态点，并加入低对比扫描纹理和暗角 | 一致 |
| 首屏比例 | 左侧标题与行动按钮，右侧大幅媒体，整体接近满屏 | 桌面采用 42/58 双栏和约一屏高度；移动端改为内容优先的单栏 | 一致 |
| 字体层级 | 超大粗体主标题、紧凑章节标题、等宽技术标记 | 主标题使用 72–82px 流体范围，章节/项目/正文逐级收敛，技术读数使用本地等宽字体 | 一致 |
| 媒体语言 | 深色画面、切角边框、蓝色细线和角标 | 首屏与项目封面均使用切角、细边、角标、扫描层和悬停缩放 | 一致 |
| 项目节奏 | 四项作品交替图文排列，编号贯穿 | 作品严格按简历顺序排列，桌面左右交替，移动端保持编号—媒体—文字顺序 | 一致 |
| 技术与关于 | 四列技术栈，关于区域为三列信息结构 | 1440px 为四列技术卡和三列关于卡；1100px 以下逐步降为两列/单列 | 一致 |
| 联系与页脚 | 大型描边联系框、克制的页脚 | 联系方式以双通道切角框呈现，页脚保留返回顶部和构建信息 | 一致 |
| 动效 | 轻微视差、滚动显现、媒体悬停、桌面光标轨迹 | 仅使用 `transform`/`opacity`；移动与减少动效模式自动停用非必要效果 | 一致 |
| 素材真实性 | 概念稿以游戏画面表达最终方向 | 首版主动改为抽象技术封面，并明确标注“项目素材待补充”；未配置视频时不显示播放按钮 | 有意偏离，以符合内容真实性要求 |
